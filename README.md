# Homebrew Taps

개인적으로 사용하는 앱을 관리하는 Homebrew tap입니다.

## BrowserOpener

Apple Silicon 및 macOS 13 Ventura 이상에서 설치할 수 있습니다.

```sh
brew install --cask blood72/taps/browseropener
```

[BrowserOpener](https://github.com/blood72/BrowserOpener)는 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 설치가 성공해도 Gatekeeper가 실행을 차단할 수 있습니다. 이 tap은 quarantine을 제거하거나 보안 설정을 변경하지 않습니다.
